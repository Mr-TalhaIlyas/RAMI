## Baseline Adaptation:
Summary of Baselines and Experimental Setups

| **Category**                                  | **Model / Method**                                      | **Modalities**                    | **Key Adaptations/Notes**                                                                                                                                                                      |
|-----------------------------------------------|---------------------------------------------------------|-----------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Seizure Detection & Classification**        | GESTURES [paper](https://ieeexplore.ieee.org/document/8629065)                            | Optical Flow                      | Privacy-preserving, optical flow-based seizure classification.                                                                                                                               |
|                                               | SETR [paper](https://link.springer.com/chapter/10.1007/978-3-031-43904-9_21)                                | Optical Flow                      | Optimized optical flow approach for seizure detection.                                                                                                                                       |
|                                               | TCN [paper](https://arxiv.org/abs/1611.05267)                                     | Optical Flow                      | Adapted for 10-second segments for seizure onset detection.                                                                                                                                  |
|                                               | CNN-LSTM (Region-based) [paper](https://ieeexplore.ieee.org/document/8629065)       | RGB (optical flow substituted)    | Uses region-based features with optical flow substituted for RGB to preserve privacy.                                                                                                          |
|                                               | CNN-LSTM (Landmark-based) [paper](https://ieeexplore.ieee.org/document/8629065)     | Optical Flow & Pose               | Fuses optical flow and 2D pose data to capture detailed movement patterns.                                                                                                                   |
|                                               | TCN+AGCN [paper](https://ieeexplore.ieee.org/document/9663770)                                | RGB & Keypoints                   | Combines TCN for video and AGCN for keypoints, with knowledge distillation for alignment.                                                                                                     |
|                                               | VSViG [paper](https://link.springer.com/chapter/10.1007/978-3-031-73007-8_14)                                    | Pose                              | SOTA pose-based approach tailored for seizure classification.                                                                                                                                |
| **ECG-based Benchmarks**                      | OCSVM [paper](https://www.mdpi.com/1660-4601/20/6/5000)                            | HRV                               | Leverages HRV features to analyze autonomic changes during seizures.                                                                                                                         |
|                                               | Res1DCNN [paper](https://ieeexplore.ieee.org/document/9479691)                             | Raw ECG                           | End-to-end architecture for direct seizure detection from raw ECG signals.                                                                                                                   |
| **Multimodal Fusion (Handling Missing Modalities)** | ACN [paper](https://arxiv.org/abs/2106.14591)                                     | —                                 | Employs adversarial training to align features across modalities.                                                                                                                            |
|                                               | CMFT [paper](https://www.sciencedirect.com/science/article/abs/pii/S0950705122008814)                                     | —                                 | Utilizes modality masking and shared feature learning to handle missing modalities.                                                                                                          |
|                                               | MFI [paper](https://link.springer.com/chapter/10.1007/978-3-031-16443-9_18)                                 | —                                 | Uses stochastic modality omission during training to improve robustness against missing data.                                                                                                  |
